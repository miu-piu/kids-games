# Animals Click

Самостоятельная детская PWA-галерея. Основной экран содержит только одну фотографию. Нет меню, подписей, кнопок, рекламы, аналитики, внешних зависимостей, разрешений и внешних ссылок.

## Запуск

Из корня `kids-games`:

```sh
python3 -m http.server 8000
```

Открыть `http://localhost:8000/animals-click/`. Не открывать через `file://`.
На Android для установки нужен HTTPS-хостинг (или localhost через USB `adb reverse tcp:8000 tcp:8000`). Обычный HTTP по IP компьютера в Wi-Fi не обеспечивает работу Service Worker и установку PWA.

Для GitHub Pages, если он включён для этого репозитория, путь будет `/kids-games/animals-click/`. Приложение также работает на любом статическом HTTPS-хостинге; пути относительные. Настройки хостинга и другие папки этим изменением не затрагиваются.

## Установка и первая загрузка

1. Открыть HTTPS-адрес `animals-click/` в Chrome на Android с интернетом.
2. Дождаться завершения загрузки всех ресурсов. На основном экране намеренно нет индикатора кеширования.
3. В меню Chrome выбрать «Установить приложение» / «Добавить на главный экран», затем подтвердить именно установку приложения.
4. Открыть Animals с новой иконки. Адресной строки браузера быть не должно.

`manifest.webmanifest`: `display: standalone`, `orientation: portrait`, отдельные `id`, `scope` и `start_url` внутри своей папки, PNG-иконки 192/512 и maskable 512. Отображение отдельной Android-карточки зависит от того, что браузер действительно установил PWA (WebAPK), а не создал обычный ярлык.

Для точной технической проверки готовности offline через DevTools на первой загрузке:

```js
const registration = await navigator.serviceWorker.ready;
const cache = await caches.open(`animals-click:${registration.scope}:v2`);
console.log((await cache.keys()).length === 17); // true = полный precache
```

Worker активируется только после успешного `addAll` всех 17 маршрутов/файлов, включая все девять WebP. PNG-исходники и документация не кешируются: они не используются приложением. Первое отображение картинки ещё не означает, что весь offline-кеш уже готов. Если первая загрузка прервалась, повторно открыть приложение с интернетом.

## Жесты и таймер

- Влево — следующий кадр, вправо — предыдущий; цикл замкнут.
- Горизонтальная дистанция ≥18% ширины, минимум 70 и максимум 120 CSS px; горизонтальная составляющая минимум в 1,8 раза больше вертикальной.
- Продолжительность свайпа 90–900 мс. Долгое удержание и последующее перетаскивание не переключают кадр.
- Вертикальное начало движения, мультикасание, отменённый жест, тап и мелкое движение игнорируются.
- Один законченный жест — один переход; защита от повторов 350 мс.
- Каждые 30 секунд — автоматический переход. Только принятый свайп и автоматический переход начинают новый отсчёт; тап и случайное касание его не сбрасывают.
- В фоне отсчёт приостанавливается. Возврат начинает новые 30 секунд без накопленных переходов.
- Один `<img>`, `object-fit: cover`, центр; предварительное декодирование соседних кадров, мягкий переход 150 мс.
- Скролл, выделение, контекстное меню, drag и масштабирование жестами отключены средствами страницы. Системные настройки доступности могут переопределять ограничения масштабирования.

## Проверка offline

После успешного кеширования выключить Wi-Fi и мобильную сеть (режим полёта), закрыть и повторно открыть установленное приложение. Просвайпать все девять картинок в обе стороны, дождаться автоперехода. В браузерном тесте дополнительно проверяется перезагрузка и навигационный fallback без сети. После кеширования файлы сценария обслуживаются cache-first; браузер сам может проверять обновление Service Worker.

## Android / Samsung Screen Pinning

Приложение не включает закрепление и не запрещает системный выход JavaScript-кодом. Оно подготовлено к работе как установленная standalone PWA.

1. В настройках телефона найти «Закрепление приложения». На Samsung обычно: «Безопасность и конфиденциальность» → «Другие параметры безопасности» → разрешить закрепление приложений. Названия зависят от версии One UI.
2. Включить запрос PIN/блокировки при откреплении.
3. Открыть установленный Animals, затем список последних приложений.
4. Нажать иконку Animals над его карточкой → «Закрепить приложение».
5. Проверить, что обычный системный свайп не открывает главный экран/другие приложения, а горизонтальные свайпы по фотографии продолжают менять кадры.
6. Откреплять способом, который покажет сам Android, с подтверждением PIN.

Физический Android, реальная установка, отдельная карточка и свайпы в системном закреплении здесь не тестировались. Без установки WebAPK некоторые браузеры могут создавать карточку/ярлык с другим поведением — это нужно проверить на конкретном телефоне.

Официальные инструкции: https://support.google.com/android/answer/9455138 и https://www.samsung.com/us/support/answer/ANS10004865/ .

## Изображения

В галерее девять отдельно сгенерированных фотографий. Арич исключён из слайд-шоу и офлайн-кеша по просьбе пользователя; ранее созданные файлы сохранены в репозитории.

| WebP | Животное |
| --- | --- |
| `02-kitten.webp` | Котёнок |
| `03-corgi.webp` | Щенок корги |
| `04-rabbit.webp` | Кролик |
| `05-calf.webp` | Телёнок-бычок |
| `06-goat.webp` | Козочка-козлёнок |
| `07-lamb.webp` | Ягнёнок |
| `08-chick.webp` | Цыплёнок |
| `09-duckling.webp` | Утёнок |
| `10-hedgehog.webp` | Ёжик |

WebP: 1440×2560, точные 9:16, качество 92. PNG-оригиналы: 940–941×1672, сохранены без изменений в `assets/images/originals/`. Размер WebP увеличен при конвертации; это не добавляет деталей к исходной генерации. Визуально проверено центральное кадрирование 412×915: животные целиком в кадре. На существенно иных соотношениях экрана `cover` может потребовать новой композиции.

## Проверки

```sh
node animals-click/tests/logic.cjs
```

52 проверки прошли в симулированной среде DOM/Service Worker: свайпы и отбрасывание случайных жестов, защита повторов, оба циклических края, точные 30 секунд, сброс только на переходах, фон/возврат, все 17 кешируемых путей, offline-ответы и fallback, отказ установки при отсутствующем ресурсе, изоляция кешей других игр. Также проверены синтаксис JS, JSON manifest, декодирование всех PNG/WebP, размеры и кадрирование.

Полный Chromium-прогон подготовлен:

```sh
# Требует Node.js и Playwright с установленным Chromium.
node animals-click/tests/check.cjs
```

В этой среде Chromium отсутствует, загрузка браузера не удалась, localhost недоступен облачному браузеру. Поэтому `tests/check.cjs` НЕ прошёл браузерный прогон; реальная установка, офлайн-перезагрузка в браузере и Android Screen Pinning остаются для проверки на устройстве. Это ограничение среды, а не утверждение об успешном тестировании.

```text
animals-click/

│           └── 01-arich.png … 10-hedgehog.png

    └── check.cjs
```

При изменении app/assets повысить `v2` в `service-worker.js`, чтобы сформировать новый полный кеш. Worker удаляет только устаревшие кеши Animals Click своего scope; кеши остальных игр сохраняются.
