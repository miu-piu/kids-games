# speech-games

Спокойные мини-игры для ребёнка на узнавание, память и развитие словаря.

## Концепция

Не линейные «100 уровней», а отработка небольших наборов понятий. Игра возвращает текущие слова, пока они не закрепятся, после чего открывает следующий набор. Прогресс хранится локально на устройстве.

## Базовая игра

- «Найди пару» на эмодзи
- мультитач: две карточки можно открывать двумя пальцами
- найденная пара выезжает крупно и остаётся до тапа
- автоматическое русское произношение слова, если системный TTS доступен
- кнопка повторного произношения
- детский лок; родительский режим открывается долгим удержанием замка
- fullscreen PWA и офлайн-кэш
- адаптивная раскладка для телефона и небольшого Android-планшета

## Установка

После включения GitHub Pages открыть сайт в Chrome на Android и выбрать «Установить приложение» / «Добавить на главный экран».
