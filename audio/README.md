# Yandex SpeechKit audio

Файлы в этой папке генерируются GitHub Action `Generate Yandex SpeechKit voice`.

В приложении они имеют приоритет над системным Android TTS. Если файла нет, игра автоматически использует системный русский голос.

Секрет API не хранится в коде и не должен попадать в публичный репозиторий.
