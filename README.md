# kids-games

Коллекция самостоятельных детских PWA-игр.

Каждая игра живёт в своей папке и содержит собственные `index.html`, `manifest.webmanifest`, `sw.js`, иконку и остальные ресурсы. Пути внутри игр относительные, поэтому каждая PWA имеет собственный scope и может открываться независимо.

## Игры

- `speech-games/` — «Найди пару — слова»: память, узнавание и развитие словаря.
- `water-sort/` — спокойная сортировка по бутылочкам.

## Правило структуры

```text
kids-games/
├── README.md
├── speech-games/
│   ├── index.html
│   ├── manifest.webmanifest
│   ├── sw.js
│   └── ...
└── water-sort/
    ├── index.html
    ├── manifest.webmanifest
    ├── sw.js
    └── ...
```

Новые игры добавляются отдельными папками на этом же уровне.
