# Зверята

Самостоятельная детская PWA-галерея. Основной экран содержит только одну фотографию. Нет меню, подписей, кнопок, рекламы, аналитики, внешних зависимостей, разрешений и внешних ссылок.

## Запуск

Из корня `kids-games`:

```sh
python3 -m http.server 8000
```

Открыть `http://localhost:8000/animals-click/`. Не открывать через `file://`.
На Android для установки нужен HTTPS-хостинг (или localhost через USB `adb reverse tcp:8000 tcp:8000`). Обычный HTTP по IP компьютера в Wi-Fi не обеспечивает работу Service Worker и установку PWA.

Для GitHub Pages, если он включён для этого репозитория, путь будет `/kids-games/animals-click/`. Приложение также работает на любом статическом HTTPS-хостинге; пути относительные. Настройки хостинга и другие папки этим изменением не затрагиваются.

## Установка и первая загрузка

1. Открыть HTTPS-адрес `animals-click/` в Chrome на Android с интернетом.
2. Дождаться завершения загрузки всех ресурсов. На основном экране намеренно нет индикатора кеширования.
3. В меню Chrome выбрать «Установить приложение» / «Добавить на главный экран», затем подтвердить именно установку приложения.
4. Открыть Зверята с новой иконки. Адресной строки браузера быть не должно.

`manifest.webmanifest`: `display: standalone`, `orientation: portrait`, отдельные `id`, `scope` и `start_url` внутри своей папки, PNG-иконки 192/512 и maskable 512. Отображение отдельной Android-карточки зависит от того, что браузер действительно установил PWA (WebAPK), а не создал обычный ярлык.

Для точной технической проверки готовности offline через DevTools на первой загрузке:

```js
const registration = await navigator.serviceWorker.ready;
const cache = await caches.open(`animals-click:${registration.scope}:v6`);
console.log((await cache.keys()).length === 66); // true = полный precache
```

Worker активируется только после успешного `addAll` всех 66 маршрутов/файлов, включая все 58 WebP. PNG-исходники и документация не кешируются: они не используются приложением. Первое отображение картинки ещё не означает, что весь offline-кеш уже готов. Если первая загрузка прервалась, повторно открыть приложение с интернетом.

## Жесты и таймер

- Влево — следующий кадр, вправо — предыдущий; цикл замкнут.
- Горизонтальная дистанция ≥18% ширины, минимум 70 и максимум 120 CSS px; горизонтальная составляющая минимум в 1,8 раза больше вертикальной.
- Продолжительность свайпа 90–900 мс. Долгое удержание и последующее перетаскивание не переключают кадр.
- Вертикальное начало движения, мультикасание, отменённый жест, тап и мелкое движение игнорируются.
- Один законченный жест — один переход; защита от повторов 350 мс.
- Каждые 30 секунд — автоматический переход. Только принятый свайп и автоматический переход начинают новый отсчёт; тап и случайное касание его не сбрасывают.
- В фоне отсчёт приостанавливается. Возврат начинает новые 30 секунд без накопленных переходов.
- Один `<img>` с полным кадром 9:16, автоматически вписанным по ширине или высоте и центрированным; `object-fit: cover` внутри рамки того же соотношения; мягкий размытый фон той же фотографии заполняет края; предварительное декодирование соседних кадров, мягкий переход 150 мс.
- Скролл, выделение, контекстное меню, drag и масштабирование жестами отключены средствами страницы. Системные настройки доступности могут переопределять ограничения масштабирования.

## Проверка offline

После успешного кеширования выключить Wi-Fi и мобильную сеть (режим полёта), закрыть и повторно открыть установленное приложение. Просвайпать все 58 картинок в обе стороны, дождаться автоперехода. В подготовленном браузерном тесте дополнительно проверяется перезагрузка и навигационный fallback без сети. После кеширования файлы сценария обслуживаются cache-first; браузер сам может проверять обновление Service Worker.

## Android / Samsung Screen Pinning

Приложение не включает закрепление и не запрещает системный выход JavaScript-кодом. Оно подготовлено к работе как установленная standalone PWA.

1. В настройках телефона найти «Закрепление приложения». Включить штатную функцию; путь и название пункта зависят от модели и версии Android / One UI.
2. Включить запрос PIN/блокировки при откреплении.
3. Открыть установленный Зверята, затем список последних приложений.
4. Нажать иконку Зверята над его карточкой → «Закрепить приложение».
5. Проверить, что обычный системный свайп не открывает главный экран/другие приложения, а горизонтальные свайпы по фотографии продолжают менять кадры.
6. Откреплять способом, который покажет сам Android, с подтверждением PIN.

Физический Android, реальная установка, отдельная карточка и свайпы в системном закреплении здесь не тестировались. Без установки WebAPK некоторые браузеры могут создавать карточку/ярлык с другим поведением — это нужно проверить на конкретном телефоне.

Официальные инструкции: https://support.google.com/android/answer/9455138 и https://www.samsung.com/us/support/answer/ANS10004865/ .

## Проверки

```sh
node animals-click/tests/logic.cjs
```

105 проверок прошли в симулированной среде DOM/Service Worker: свайпы и отбрасывание случайных жестов, защита повторов, оба циклических края, точные 30 секунд, сброс только на переходах, фон/возврат, все 66 кешируемых путей, offline-ответы и fallback, отказ установки при отсутствующем ресурсе, изоляция кешей других игр. Также проверены синтаксис JS, JSON manifest, декодирование всех PNG/WebP, размеры и кадрирование.

Полный Chromium-прогон подготовлен:

```sh
# Требует Node.js и Playwright с установленным Chromium.
node animals-click/tests/check.cjs
```

В этой среде Chromium отсутствует, загрузка браузера не удалась, localhost недоступен облачному браузеру. Поэтому `tests/check.cjs` НЕ прошёл браузерный прогон; реальная установка, офлайн-перезагрузка в браузере и Android Screen Pinning остаются для проверки на устройстве. Это ограничение среды, а не утверждение об успешном тестировании.

## Расширение серии

58 активных животных. Арич исключён, корги заменён щенком ирландского красного сеттера выставочного типа. Тигрёнок амурский, лебедь взрослый, павлин с полностью распущенным веером. Бабочка и божья коровка сверху; стрекоза и улитка сбоку. Естественная среда остаётся узнаваемой, но мягкой и спокойной; морские кадры и лист для насекомых допускают однородный фон. Старые Арич/корги остаются историческими файлами и не входят в показ или precache.

Предзагрузка удерживает максимум три декодированных изображения (текущее и два соседа), вместо накопления всей серии в памяти. Это ограничение памяти проверено, но причина сообщённого сворачивания Android-приложения при свайпе в режиме полёта не подтверждена и исправление этого поведения на устройстве не доказано.

Название для установки: «Зверята». Иконки `zveryata-v2-192.png`, `zveryata-v2-512.png` и `zveryata-v2-maskable-512.png` подготовлены из приложенной пользователем картинки. Фон исходной картинки расширен встроенной генерацией изображений до всего квадрата без белых углов и заранее скруглённой рамки. Щенок центрирован с запасом под системную маску; проверен круг радиуса 40% ширины. Все используемые варианты иконки имеют одинаковую безопасную композицию. Исходник расширенного фона и точный промпт сохранены в `assets/icons/`. Старые иконки сохранены как исторические файлы, но не используются манифестом или offline-кешем.

Центровка использует CSS Grid и динамическую высоту viewport (`dvh`) с fallback на `vh`. Основной кадр никогда не масштабируется выше размера, позволяющего показать его целиком. Размытая подложка использует тот же URL и синхронно меняется вместе с фото; новых сетевых зависимостей нет.
